# Koch Snowflake Fractal

A Python script that generates a Koch Snowflake fractal using the `turtle` module, rendered with a custom color gradient. The generated pattern was used as the basis for a T-shirt design.

## Overview

The script recursively constructs a Koch snowflake and applies a smooth color transition across a defined palette during rendering.

## Tools Used

- Python (`turtle`, `math`)
- Claude AI, for writing and refining the fractal generation code
- Gemini AI, for generating a T-shirt design based on the fractal output

## Requirements

- Python 3.x (the `turtle` module is included in the standard library)

## Usage

Run the script from the command line:

    python meow.py

## Output

The script produces a Koch snowflake drawing with a gradient color scheme. This output was used to generate a T-shirt mockup design in a separate step.
